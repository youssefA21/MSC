MSC SAMS landing page - quick setup

1. DEPLOY: upload this whole folder to your host (Vercel, Netlify, Cloudflare Pages...).

2. SHARE PREVIEW (so WhatsApp / Instagram show the blue card when you paste the link):
   Open index.html in a text editor, search for YOUR-SITE-ADDRESS (2 places near the top)
   and replace it with your real address, for example msc-sams.vercel.app
   Then upload again.

3. VISIT COUNTS (optional, free, no cookies): create an account at goatcounter.com,
   choose a code (example: msc-sams), then in index.html find
   window.SAMS={goatcounter:''}
   and put your code inside the quotes.
   It also counts clicks on the two apply buttons, Instagram, LinkedIn, TikTok and the theme button.

4. PHOTOS: put the leaders' photos in the photos folder with these exact names:
   engy-osama.jpg, joudy-walid.jpg, mohamed-ahmed.jpg, ahmed-adel.jpg, mohamed-haitham.jpg
